## ✨ About Quick'n'Smart

**Quick'n'Smart** is an integrated Indian enterprise combining:
1. **Direct E-Commerce Retail Store**: Selling authentic South Indian handlooms (Kanjeevaram & Banarasi silks), electronics (ANC audio gadgets, smartwatches, GaN chargers), pure Vedic A2 ghee, Kashmiri saffron, and artisanal brass decor.
2. **Express Domestic Logistics & Courier Services**: Direct warehouse-to-doorstep fulfillment, Same-Day & 24-hr Chennai deliveries, Pan-India courier tracking, and doorstep Cash on Delivery (COD) / UPI pickup from our Ambattur Central Hub (600053).

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router) + TypeScript
- **Styling**: Tailwind CSS (Quick'n'Smart Palette: Purple `#7C3AED`, Speed Orange `#EA580C`, Lightbulb Gold `#F59E0B`)
- **State Management**: Zustand with persistent storage (`quicknsmart-user-storage`, `utsav-cart-storage`)
- **Database Architecture**: Supabase PostgreSQL schema with Row Level Security (RLS) policies
- **Payments**: Razorpay Indian Payment Gateway simulation (Instant UPI QR, Cards, NetBanking, COD)
- **Deployment**: Vercel
